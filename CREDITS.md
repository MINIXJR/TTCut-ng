## Third-Party Assets

### Tux (Linux Penguin Mascot)

Tux was created in 1996 by **Larry Ewing** (`lewing@isc.tamu.edu`) using The GIMP.
The vector version bundled as `ui/pixmaps/Tux.svg` is by **Larry Ewing, Simon
Budig and Garrett LeSage**; it is the file from Wikimedia Commons
(<https://commons.wikimedia.org/wiki/File:Tux.svg>), unchanged.

Tux appears, unchanged, in the TTCut-ng application logo
(`ui/pixmaps/ttcut-ng.svg`, `ui/pixmaps/ttcut-ng-small-*.svg`,
`ui/pixmaps/icons/*/ttcut-ng.png`, generated by `tools/logo/gen-logo.py`);
every logo SVG names the Tux authors in its metadata.

Original permission statement:
